# Requisitos

Requisitos derivados da [modelagem completa](../00-visao-geral/modelagem-completa.md). Cada requisito tem um ID estável, usado em commits, testes e no [backlog de épicos](../09-roadmap/backlog-epicos.md).

- **RF** — requisito funcional, por produto: [CRM](funcionais/crm.md) · [Calculator](funcionais/calculator.md) · [Engine](funcionais/engine.md) · [Off-Grid](funcionais/offgrid.md) · [Plataforma](funcionais/plataforma.md)
- **RNF** — [requisitos não funcionais](nao-funcionais.md)
- **RN** — [regras de negócio](regras-de-negocio.md)

**Fase** indica quando o requisito entra: `MVP1` (CRM + Calculator), `MVP2` (Engine), `MVP3` (Off-Grid), `F11` (execução e lifecycle), `F12` (inteligência).
