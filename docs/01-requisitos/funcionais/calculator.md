# Requisitos funcionais — Solar Calculator

Épicos `EPIC-CALC-*`. Ferramenta rápida de pré-viabilidade, **não substitui projeto de engenharia**. Vendável isoladamente (funciona sem CRM). Memorial das fórmulas em [06-calculos](../../06-calculos/calculator.md).

| ID          | Requisito                                                                                                                                                                                                                                                    | Fase |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---- |
| RF-CALC-001 | Criar sessão de cálculo com cliente/local (endereço, CEP, coordenadas, concessionária, perfil)                                                                                                                                                               | MVP1 |
| RF-CALC-002 | Informar consumo mensal ou histórico de até 12 meses; receber da fatura validada quando houver CRM                                                                                                                                                           | MVP1 |
| RF-CALC-003 | Informar tarifa, grupo (A/B), modalidade e, quando aplicável, demanda e simultaneidade                                                                                                                                                                       | MVP1 |
| RF-CALC-004 | Obter recurso solar (HSP) por município/UF com opção de entrada manual                                                                                                                                                                                       | MVP1 |
| RF-CALC-005 | Premissas editáveis: potência do módulo, perdas/PR, orientação e inclinação aproximadas, área disponível                                                                                                                                                     | MVP1 |
| RF-CALC-006 | Premissas financeiras: custo/Wp ou kit, mão de obra, margem, reajuste tarifário, financiamento opcional                                                                                                                                                      | MVP1 |
| RF-CALC-007 | Calcular potência FV estimada, nº de módulos e área aproximada                                                                                                                                                                                               | MVP1 |
| RF-CALC-008 | Calcular geração mensal e anual e percentual de compensação                                                                                                                                                                                                  | MVP1 |
| RF-CALC-009 | Calcular economia anual, economia acumulada, investimento, payback simples e fluxo de caixa preliminar                                                                                                                                                       | MVP1 |
| RF-CALC-010 | Semáforo de pré-viabilidade (verde/amarelo/vermelho) com alertas explicados                                                                                                                                                                                  | MVP1 |
| RF-CALC-011 | Score de confiança do cálculo                                                                                                                                                                                                                                | MVP1 |
| RF-CALC-012 | Preview instantâneo no formulário usando o mesmo motor da API                                                                                                                                                                                                | MVP1 |
| RF-CALC-013 | Salvar `QuickCalculationSnapshot` imutável (inputs, outputs, versão do algoritmo e da regra, usuário, data, avisos)                                                                                                                                          | MVP1 |
| RF-CALC-014 | Vermelho bloqueia proposta definitiva; amarelo recomenda encaminhar ao Engine Studio                                                                                                                                                                         | MVP1 |
| RF-CALC-015 | Enviar resultado ao CRM e vincular à oportunidade                                                                                                                                                                                                            | MVP1 |
| RF-CALC-016 | Gráficos: geração × consumo mensal e fluxo de caixa                                                                                                                                                                                                          | MVP1 |
| RF-CALC-017 | Entradas opcionais de orientação e inclinação do telhado, com alertas orientativos (inclinação abaixo de 10°, orientação fora do Norte) e inclinação recomendada por latitude. Origem: [EF-M02 a EF-M04](../../referencias/energif-2023/regras-e-medidas.md) | MVP1 |
| RF-CALC-018 | Classificar a geração em micro (≤ 75 kW), mini (≤ 5 MW) ou usina, com limites parametrizados no Rules Engine. Origem: [EF-M06](../../referencias/energif-2023/regras-e-medidas.md)                                                                           | MVP1 |
| RF-CALC-019 | Exibir as premissas e os fatores de perda usados e o aviso de que o resultado é preliminar e não substitui projeto. Origem: [EF-R02, EF-R08](../../referencias/energif-2023/regras-e-medidas.md)                                                             | MVP1 |
