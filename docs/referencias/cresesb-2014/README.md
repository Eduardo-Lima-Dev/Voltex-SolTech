**Nota sobre ENG-F03 (Vmpp):** nossa premissa (usar β de Voc quando a ficha não traz β de Vmpp) é **conservadora nos dois sentidos**: como o manual diz que β_Vmp é "geralmente maior" (menos negativo) que β_Voc, usar β_Voc **subestima** o Vmpp no quente (limite mínimo do MPPT) e **superestima** o Vmpp no frio (limite máximo do MPPT). O manual sugere aproximar β_Vmp por γ; a escolha entre β_Voc e γ vira **parâmetro da regra `engine.design`** quando o responsável técnico revisar. A premissa fica registrada no resultado (`BETA_VOC_ASSUMED`). O limite crítico de segurança é o Voc, que usa o coeficiente próprio.
