# Glossário

| Termo                              | Significado                                                                           |
| ---------------------------------- | ------------------------------------------------------------------------------------- |
| **Integradora**                    | Empresa que vende, projeta, instala e mantém sistemas fotovoltaicos; cliente da suíte |
| **Tenant**                         | Empresa cliente da suíte; unidade de isolamento de dados                              |
| **UC**                             | Unidade consumidora (ponto de consumo atendido pela concessionária)                   |
| **Concessionária / distribuidora** | Empresa que distribui energia na região e homologa a conexão                          |
| **Grupo A / Grupo B**              | Grupos tarifários: A (alta/média tensão, com demanda contratada) e B (baixa tensão)   |
| **On-grid**                        | Sistema conectado à rede                                                              |
| **Off-grid**                       | Sistema isolado, com armazenamento                                                    |
| **Híbrido**                        | On-grid com armazenamento/backup                                                      |
| **Grid Zero**                      | Operação sem injeção de energia na rede                                               |
| **BESS**                           | Sistema de armazenamento de energia em baterias                                       |
| **HSP**                            | Horas de sol pleno (irradiação diária em kWh/m²/dia equivalente)                      |
| **PR**                             | Performance ratio — razão entre a geração real e a ideal, por perdas do sistema       |
| **kWp / Wp**                       | Potência de pico do arranjo FV                                                        |
| **Pmpp, Vmpp, Impp**               | Potência, tensão e corrente no ponto de máxima potência do módulo                     |
| **Voc / Isc**                      | Tensão de circuito aberto / corrente de curto-circuito                                |
| **MPPT**                           | Rastreador do ponto de máxima potência do inversor/controlador                        |
| **String**                         | Série de módulos ligados em série                                                     |
| **DC/AC**                          | Relação entre a potência CC do arranjo e a potência CA do inversor                    |
| **DoD**                            | Profundidade de descarga da bateria                                                   |
| **SOC**                            | Estado de carga da bateria                                                            |
| **Payback**                        | Tempo para recuperar o investimento pela economia gerada                              |
| **O&M**                            | Operação e manutenção da planta instalada                                             |
| **ART / RRT**                      | Anotação / Registro de Responsabilidade Técnica                                       |
| **OCR**                            | Reconhecimento óptico de caracteres (leitura da conta de energia)                     |
| **Snapshot**                       | Registro imutável de inputs, outputs, versões e premissas de um cálculo/proposta      |
| **Project ID / `projectCode`**     | Identificador global que acompanha o ciclo de vida do projeto                         |
| **Margin Guard**                   | Controle que impede venda abaixo da margem mínima sem aprovação                       |
| **Rules Engine**                   | Motor de regras regulatórias versionadas                                              |
| **Regulation-as-Code**             | Regulação tratada como dado versionado, não como constante de código                  |
| **Digital Thread**                 | Fio condutor de dados do lead ao O&M, sem recadastro                                  |
| **Evidence Pack**                  | Conjunto organizado de evidências de um projeto                                       |
| **Semáforo**                       | Classificação verde/amarelo/vermelho de pré-viabilidade do Calculator                 |
