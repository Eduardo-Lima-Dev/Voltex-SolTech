## Como manter

- Decisão de arquitetura nova ou que mude uma existente → novo [ADR](04-arquitetura/adr/README.md).
- Fórmula nova ou alterada → atualizar o memorial em `06-calculos/` junto com o código.
- Requisito novo → ID novo em `01-requisitos/` e épico no backlog.
- Evento novo → catálogo de eventos e schema em `@voltex/shared`.
